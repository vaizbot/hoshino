# 👋 你好，这里是 Hoshino

我的个人网站：记录日常、收集故事、写点东西。白天写代码，晚上写小说，声音是我的执念——全站文章都能用「我的声音」读给你听。

🌐 网站：**https://vaizbot.github.io/hoshino/**

## ✨ 特色

- 🎙️ **五种声线朗读**：普通话 / 吴侬软语 / English / 日本語 / 한국어，点段落三下即可从那里开始听；
- 🌍 **AI 翻译**：正文一键中英互译；
- ✍️ **写作工作台**：大纲地图（分支叙事树）+ 人设库 + 自动保存，为写小说而生；
- 🎵 **音乐播放器**：网易云歌单 + 同步歌词；
- 💬 **评论与留言板**：欢迎留下脚印。

## 🛠 技术栈

Vue 3 · TypeScript · Tailwind CSS · Supabase（数据库 / Storage / Edge Functions）· Cloudflare（定时任务）· MiMo TTS
